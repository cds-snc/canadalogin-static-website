# Problems with creating a profile

When signing up for CanadaLogin, you’ll need to provide some basic information to create your profile, including your:

- Name

If you’re having issues entering this information, see our troubleshooting topics below:

## You are not sure what to enter for your name

Try the following:

- **First name (optional)**: You can choose to enter a first name or leave it blank.
- **Last name (required)**: You must enter your last name. If you do not have a last name, write your legal name in this field.

If you are still having issues {% link links.contactUsers 'contact customer support' %} with your issue and tell them what you’ve tried.
