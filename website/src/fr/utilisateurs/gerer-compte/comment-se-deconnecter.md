# Comment se déconnecter

Pour vous déconnecter, suivez les étapes suivantes : 

1. Assurez-vous d’avoir enregistré tous vos changements.
2. À partir du service pour lequel vous avez ouvert une session, ouvrez le menu en haut de la page et cliquez sur « Se déconnecter ».
3. Lorsqu’une fenêtre contextuelle vous y invitera, confirmez que vous souhaitez vous déconnecter. 
4. Un message devrait vous confirmer votre déconnexion.
5. Si vous avez terminé d’utiliser le service, nous vous recommandons de fermer l’onglet.
