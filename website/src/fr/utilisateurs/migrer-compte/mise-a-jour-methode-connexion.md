# Mettre à jour votre méthode de connexion pour passer à ConnexionCanada

ConnexionCanada vient remplacer définitivement la méthode de connexion suivante :
- Nom d’utilisateur et mot de passe de CléGC

ConnexionCanada remplace temporairement la méthode de connexion suivante :
- Partenaires de connexion Interac (banques et coopératives de crédit)

<gcds-notice type="info" notice-title-tag="h3" notice-title="Guides connexes">
  <gcds-text>{% link links.whycanadaloginisreplacingpartners 'Pourquoi ConnexionCanada remplace les méthodes de connexion existantes' %}</gcds-text>
</gcds-notice>

<br>

Certains services vont commencer à utiliser ConnexionCanada avant d’autres. Il se peut que vous deviez continuer à utiliser d’autres méthodes de connexion tant que tous les services n’auront pas adopté ConnexionCanada.

**Vous devrez mettre à jour votre méthode de connexion pour tous les services pour lesquels vous possédez déjà un compte.** Vous devriez recevoir un courriel lorsque les services que vous utilisez commenceront à adopter ConnexionCanada.

## Comment mettre à jour votre méthode de connexion pour passer à ConnexionCanada

<ul class="list-disc mb-300">
  <li>Connectez-vous à un service en cours de migration.</li>
  <li>Sélectionnez la méthode de connexion que vous avez utilisée lors de votre dernière connexion à ce service. Des instructions vous indiqueront comment mettre à jour votre méthode de connexion. Suivez ces étapes :</li>
  <ol class="list-decimal">
  <li>Créez un identifiant ConnexionCanada ou utilisez votre identifiant ConnexionCanada existant.</li>
  <li>Connectez-vous à l’aide de CléGC ou d’un partenaire de connexion Interac. Sélectionnez la méthode de connexion que vous avez utilisée lors de votre dernière connexion à ce service.</li>
    <ul class="list-disc">
      <li>S’il n’existait qu’une seule méthode de connexion, il se peut que vous n’ayez pas à choisir.</li>
      <li>Il se peut que vous deviez procéder à l’authentification multifacteur de CléGC ou du service d’ouverture de session Interac.</li>
    </ul>
    <li>Vous pouvez maintenant utiliser ConnexionCanada pour accéder à votre compte existant avec ce service. À l’avenir, vous n’utiliserez que ConnexionCanada pour accéder à ce service. Vous pouvez utiliser le même identifiant ConnexionCanada pour accéder à d’autres services participants.</li>
  </ol>
</ul>

### Si votre compte est introuvable

Après la mise à jour de votre méthode de connexion, il se peut que vous n’ayez pas accès à votre compte existant pour ce service. Cela pourrait être dû à l’une des raisons suivantes :
- Vous avez utilisé une autre CléGC ou un autre partenaire de connexion Interac que lors de votre dernier accès au service.
- Il s’agit de votre toute première connexion à ce service.

S’il ne s’agit pas de votre première connexion à ce service, mais que vous avez utilisé la mauvaise CléGC ou le mauvais partenaire de connexion Interac, vous devez créer un nouvel identifiant ConnexionCanada. Utilisez une adresse courriel différente et répétez le processus de liaison en utilisant la bonne CléGC ou le bon partenaire de connexion Interac.

</gcds-notice>

<br>

Il est possible que vous n’ayez pas de compte pour ce service. Si tel est le cas, vous devrez créer un nouveau compte pour ce service.

### Si votre ancienne méthode de connexion a expiré

Si cela fait plus d’un an que vous n’avez pas utilisé de partenaire de connexion Interac pour vous connecter, il se peut que votre méthode de connexion ait expiré.

Si cela fait plus de deux ans que vous n’avez pas utilisé CléGC pour vous connecter, il se peut que votre méthode de connexion ait expiré. 

Si votre ancienne méthode de connexion a expiré, vous ne pourrez pas la relier à votre identifiant ConnexionCanada. Vous devrez créer un nouveau compte pour ce service. 

Vous pourriez être en mesure de récupérer votre compte pour ce service. Le processus de récupération de compte diffère selon les services. Pour obtenir de l’aide, veuillez vous reporter à la documentation d’aide du service en question ou contacter le centre d’appel de ce service.
