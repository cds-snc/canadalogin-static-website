# Mettre à jour votre méthode de connexion

Connexion GC est en voie de remplacer les méthodes de connexion suivantes : 
- nom d'utilisateur et mot de passe de CléGC
- partenaires de connexion Interac (institutions financières)

<gcds-notice type="info" notice-title-tag="h3" notice-title="Related help guides">
  <gcds-text>{% link links.issuespassword 'Why CanadaLogin is replacing GCKey and Interac sign-in partners' %}</gcds-text>
</gcds-notice>

Certains services commenceront à utiliser Connexion GC avant d'autres. Jusqu'à ce que tous les services utilisent Connexion GC, vous devrez peut-être continuer à utiliser d'autres méthodes de connexion.

**Vous devrez mettre à jour votre méthode de connexion sur chaque service où vous avez déjà un compte.** Vous devriez recevoir un courriel lorsque les services que vous utilisez commencent à utiliser Connexion GC.

## Étapes

<ul class="list-disc mb-300">
  <li>Connectez-vous à un service en migration.</li>
  <li>Sélectionnez la méthode de connexion que vous avez utilisée la dernière fois que vous vous êtes connecté à ce service. Vous verrez des instructions pour mettre à jour votre méthode de connexion. Suivez les étapes :</li>
  <ol class="list-decimal">
  <li>Créez un authentifiant Connexion GC ou utilisez votre Connexion GC existant.</li>
  <li>Connectez-vous avec CléGC ou votre institution financière. Sélectionnez la méthode que vous avez utilisée la dernière fois que vous vous êtes connecté à ce compte.</li>
    <ul class="list-disc">
      <li>S'il n'y avait qu'une seule ancienne méthode de connexion, vous n'aurez peut-être pas à choisir.</li>
      <li>Vous devrez peut-être effectuer l'authentification multifactorielle de votre CléGC ou de votre institution financière.</li>
    </ul>
    <li>Vous pouvez désormais utiliser Connexion GC pour accéder à votre compte. Vous pouvez utiliser le même authentifiant Connexion GC pour accéder à d’autres services participants.</li>
  </ol>
</ul>

### Une fois votre méthode mise à jour

Vous pouvez maintenant accéder à votre compte existant sur le service. À partir de maintenant, vous utiliserez uniquement Connexion GC pour accéder au service.

### Si votre compte n'apparaît pas

Après avoir mis à jour votre méthode de connexion, il se peut que vous n'ayez pas accès à votre compte existant sur le service. Cela est peut-être parce que vous avez utilisé une autre ancienne méthode de connexion la dernière fois que vous avez accédé au service.

Vous devrez créer un nouveau compte pour le service. Vous pourrez peut-être récupérer votre compte sur le service.

### Si votre ancienne méthode de connexion a expiré

Si vous ne vous êtes pas connecté avec un partenaire de connexion depuis plus d'un an, votre méthode de connexion a peut-être expiré.

Si vous ne vous êtes pas connecté à CléGC depuis plus de 2 ans, votre méthode de connexion a peut-être expiré. 

Vous devrez créer un nouveau compte pour le service. Vous pourrez peut-être récupérer votre compte sur le service.
